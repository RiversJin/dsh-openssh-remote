How to read these numbers口径说明

These are "installs that have upgraded", not all users. Heartbeats only come from versions that contain the reporter (0.8.25+). Until everyone upgrades, DAU/WAU/MAU systematically under-count — so treat them as a floor and cross-check against npm downloads.
  • Deduplication — one install reports at most once every 6 hours; a row is written per install per day, and a repeated report the same day only increments a counter. Deleting <DSH_HOME>/.dsh-remote-install-id makes an install look new.
  • Time zone — days are bucketed in Asia/Shanghai, so a "day" is not UTC.
  • npm gaps — npm's daily endpoint returns 0 for some days across all packages (verified against control packages), i.e. a reporting gap rather than zero usage. Those days are flagged instead of being drawn as real zeros.
  • Privacy — only idHash (an HMAC pseudonym), version, platform, arch and node version are transmitted. The raw install ID never leaves the machine.
