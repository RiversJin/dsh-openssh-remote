What it does 能力

The harness Web UI intentionally binds 127.0.0.1. This plugin goes the other way: you connect out to the machines you maintain — through the normal DSH workspace and agent file flows, with no changes to the harness core.

🖧

Multi-machine registry

Add, edit, and switch between many SSH hosts. Password, private key, SSH agent, keyboard-interactive, and jump hosts via ProxyJump.

🗂️

Remote workspace picker

Pick a local or remote workspace from the native modal. Remote paths autocomplete over SFTP with per-keystroke latency kept in the tens of milliseconds.

🛠️

20 rw_* tools

read / write / edit / append / mkdir / remove / move / stat / exec / search / upload / download / sync / push / forward and more — all as first-class agent tools.

🔄

Conflict-aware mirror

A three-way SFTP sync keeps the remote tree mirrored locally, so @ file references, read tools, and the sidebar editor all just work.

🔐

Credentials stay local

Passwords in the OS keychain when available, TOFU host-key verification, a command audit log, and keys never leave your machine.

♻️

Self-updating

Checks npm on load, and since 0.8.24 hot-swaps its own host half — an update takes effect without restarting the harness.

Install 安装

Requires DeepSeek Harness. The plugin is a normal profile bundle.

# 1. add it to the web profile
dsh plugin --profile web add dsh-remote

# 2. start the harness (or restart it once)
dsh web

# update later
dsh plugin --profile web add dsh-remote@latest
Upgrading an old install? Versions before 0.8.24 cannot hot-swap themselves — the first hop to 0.8.24+ needs one restart. After that, updates apply without restarting.

Configuration 配置

FieldDefaultMeaning
host''Remote SSH host; empty starts disconnected.
updateModeautoauto | manual | off — self-update behaviour. Default changed to auto in 0.8.27: it checks npm on load and every 6h, then hot-swaps the host half.
updateAutoReloadtrueHot-swap the host half after an update lands. With false the update only applies on the next start and the panel shows "restart to finish".
updateCheckIntervalMs6hHow often auto mode checks npm.
auditLogfalseRecord every remote command to a local audit log.

Telemetry & privacy 数据采集

Since 0.8.25 the plugin sends one anonymous heartbeat per launch (at most once every 6 hours) so real usage can be measured — something npm download counts and GitHub clones cannot answer.
SentidHash (HMAC pseudonym), version, platform, arch, node — exactly five fields.
Never sentHostnames, usernames, paths, IPs, SSH hosts/ports/keys, your machine list, conversation content, anything from your remote sessions.
IdentityA random UUID in <DSH_HOME>/.dsh-remote-install-id. The original never leaves your machine — only its HMAC is transmitted, so it cannot be correlated or reversed.

The heartbeat is fire-and-forget: it never blocks loading and any failure is swallowed silently. See the live usage stats and the full policy.
